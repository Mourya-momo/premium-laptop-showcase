## 🚀 Quick Start

1. Clone the repository:
```bash
git clone https://github.com/Mourya-momo/premium-laptop-showcase.git
cd premium-laptop-showcase
```

2. Open in a web server (required for full functionality):
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js http-server
npx http-server

# Or use VS Code Live Server extension
```

3. Visit `http://localhost:8000` in your browser

## 🎨 Customization

### Colors
Edit the `:root` CSS variables:
```css
--primary: #1a1a2e;      /* Dark background */
--secondary: #16213e;    /* Secondary dark */
--accent: #0f3460;       /* Accent color */
--gold: #e8b547;         /* Highlight color */
```

### Products
Edit the product cards in `index.html` with your laptop details

### Content
All text and images can be easily customized in `index.html`
